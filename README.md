## 게임 소개  
피자레디 모작 하이퍼 캐주얼 모바일 게임입니다.  
Unity 3D로 구현된 피자레디(Pizza Ready) 스타일의 3D 모바일 시뮬레이션 게임입니다.

---

## 개발 기간  
총 5일 (후반부 UI 요청 후 합류)

---

## 개발 인원 및 역할  
- 총 3명 팀 프로젝트  
- **담당 역할**  
  - 로딩 씬 구현  
  - 스타트 UI 이미지 제작 및 구성  
  - 씬 전환 UI 흐름 제작 및 연동

---

## 핵심 기능  
- 로딩 이미지 및 텍스트 표시  
- 로딩 완료 후 Touch to Start UI로 자연스럽게 전환  
- 클릭 시 메인 인게임 씬으로 씬 전환  
- 모든 UI 구성과 흐름을 코드 기반으로 구현

---

##  기술 스택  
- Unity 3D  
- C#  
- GitHub (버전 관리)

---

## 회고  
`후반에 합류해 UI 파트를 빠르게 파악하고 작업하는 과정에서
씬 전환 흐름과 로딩 UI 구현에 익숙해질 수 있었고,
짧은 시간 안에 모바일 게임 UI/UX의 기본 흐름**을 익히는 좋은 경험이 되었습니다.`
